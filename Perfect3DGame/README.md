# Perfect 3D Game
A modular open-world 3D game made with Babylon.js.

## Features
- WASD camera controls
- Adjustable graphics settings
- Coin collection system
- Fully modular codebase

## How to Host
1. Upload this folder to a GitHub repo
2. Enable GitHub Pages under Settings > Pages
3. Set source to `main` and root
4. Visit your live game at `https://yourname.github.io/your-repo-name/`
